# Reels OneS News: съёмка + озвучка

Один вертикальный ролик **9:16, 50–60 секунд**. Экран телефона без звука, озвучка на компьютере. Площадки: Instagram Reels, TikTok, YouTube Shorts, VK Клипы, Telegram.

Сайт: [enterprisehub.dev](https://enterprisehub.dev). В кадре имя **OneS News**. Логотипы фирмы «1С» не показывать — на сайте их нет.

Новости подгружаются с сайта (статический JSON). В браузере лежат только тема, скрытые источники, поиск и «прочитано». В озвучке: *без аккаунта, без бэкенда под ваши данные, всё в браузере* — не «все новости офлайн».

## Часть 1. Сценарий съёмки (без звука)

Жесты медленные, палец не закрывает шапку и поле поиска.

| Сек | Кадр | Что делать |
|-----|------|------------|
| 0–3 | Хук | Быстрый скролл ленты сверху вниз. Карточки мелькают. Шапка **OneS News** уже в кадре — ничего с ней не делать. |
| 3–8 | Стоп | Просто **остановить скролл**. Не зумить, не тянуть страницу, не целиться в шапку. Контраст с хуком: мельтешение → пауза. URL уже есть в адресной строке Chrome и под именем в шапке. |
| 8–14 | Лента | Медленный скролл: сайты, Telegram, видео. Заголовки читаются, чужой сайт не открывать. |
| 14–22 | Прочитано | Тап по **заголовку** карточки (ссылка открывает вкладку — сразу вернуться на ленту). Карточка тускнеет, появляется бейдж **Прочитано**. Тап по бейджу — отметка снята, карточка снова яркая. |
| 22–30 | Отборы | Тап по **плашке источника** на карточке (например Infostart) — лента сужается, в шапке тот же источник. Плашки на карточках после этого пропадают. Сброс: тап по **Источнику** в шапке → **Все**. Затем тап по **дате** → календарь на 1 с → закрыть. Не открывать список источников в шапке первым: зрителю важнее жест «прямо с карточки». |
| 30–34 | Поиск | Тап в поиск, ввод 4–6 букв, лента фильтруется. Крестик сброса — коротко. |
| 34–36 | Тема | Тап переключателя солнце/луна. Пауза 1 с на тёмной теме. |
| 36–44 | Английский | Тап по переключателю языка в шапке (рядом с шестерёнкой) → **English**. Дождаться ленты: английские заголовки, в мета карточки источник **1C:DN**. Короткий скролл одной карточки. Снова тап по языку → **Русский**. Не уходить на 1c-dn.com. |
| 44–51 | Настройки | Шестерёнка → экран **Настройки** → блок **Источники** → снять галочку с одного канала → кнопка **Лента** внизу. |
| 51–54 | Доверие | Возврат на ленту в тёмной теме **или** короткий кадр настроек про отсутствие учётки. |
| 54–60 | Финал | Доскроллить **наверх** ленты (или остаться на шапке после возврата из настроек). Держать кадр до конца. Крупный URL — титром в монтаже, не pinch-zoom на телефоне. |

Кусок 3–8 не про «показать шапку» — она и в хуке на месте. Нужна только пауза: зритель успевает прочесть имя и адрес, пока в озвучке звучит боль («новости размазаны»). На записи экрана камеру отодвинуть нельзя.

Переключатель языка меняет и интерфейс, и ленту: английские материалы живут в **своих** днях календаря. Зарубежный источник сейчас один — **1C:DN**. В настройках галочка «English» — это не то же самое, что переключатель в шапке: для ролика нужен именно шапочный **English**, чтобы в кадре были английские заголовки.

Отметка ставится по тапу на заголовок и живёт в браузере (`ones-read`). Сброс — тап по бейджу. На телефоне подпись **Отменить** при наведении не появится (нет hover): бейдж так и пишет «Прочитано», но тап снимает статус. Чужую вкладку в ролик не клеить — в монтаже только лента: тусклая карточка → снова обычная.

Плашка источника на карточке — тот же фильтр, что список в шапке. Пока фильтр выключен, плашка есть; после тапа остаётся только выбранный канал, плашки скрываются. Сбросить — **Все** в шапке. Повторно тыкать шапочный список в этом же куске не нужно: он сам переключится вслед за плашкой.

Отдельный экран конфиденциальности на 10 секунд не нужен: одна секунда титра + фраза в озвучке.

Запасные дубли: ещё раз «прочитано / сброс», ещё раз плашка источника, ещё раз тема, ещё раз язык RU→EN→RU, ещё раз поиск, ещё раз снятие галочки.

## Часть 2. Озвучка

Темп ~2,3 слова/с. Ниже **~130 слов ≈ 58 с**. Между абзацами пауза в полсекунды.

**0:00–0:03**  
Хабр. Инфостарт. Телеграм. Ютуб. И каждый день — десять вкладок.

**0:03–0:08**  
Новости мира 1С размазаны по всему интернету.

**0:08–0:14**  
OneS News — ежедневный дайджест в одном месте. Сайт enterprisehub.dev.

**0:14–0:18**  
Открыл — лента за день: статьи, каналы, видео.

**0:18–0:24**  
Открыл материал — карточка «прочитано». Тап по бейджу — статус сброшен.

**0:24–0:30**  
Один источник — тап по плашке на карточке. В шапке то же самое. Дата — календарь.

**0:30–0:33**  
Ищешь EDT или Vanessa — поиск по заголовкам.

**0:33–0:36**  
Тема светлая или тёмная. Переключил.

**0:36–0:43**  
Не только русский: английская лента и материалы с зарубежных площадок — сейчас это 1C:DN.

**0:43–0:49**  
Лишний канал мешает? В настройках снял галочку. Без регистрации.

**0:49–0:54**  
Бэкенда под ваши данные нет: тема и прочитанное живут только в браузере.

**0:54–1:00**  
Заходите на enterprisehub.dev. Есть идея по источнику — напишите с сайта. Ссылка в профиле.

### Как читать на компьютере

- Файл WAV/FLAC, 48 kHz.
- Голос чуть быстрее разговорного, без дикторского пафоса: коллега показывает инструмент.
- Ударение: **энтерпра́йз хаб дот дев**, **уан эс ньюз** (или по-русски «уанс ньюз» — одинаково во всём ролике).
- «1С» — спокойно, как в чате разработчиков, не как реклама фирмы.

Если ролик длиннее 60 с — ускорить 0:08–0:14 или не произносить URL в середине (оставить только в конце). Куски «прочитано» и «английский» не выкидывать.
